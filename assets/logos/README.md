# Official brand logos

Grow More never ships made-up or approximated bank logos. To show a genuine logo on an account:

1. Download the **official** logo (SVG preferred) from the brand's own press / brand-assets page.
2. Save it here as: `meezan.svg`, `jazzcash.svg`, `easypaisa.svg` (or `.png` / `.webp`).
3. Reload the app — accounts created from the "Meezan Bank / JazzCash / Easypaisa" quick-start buttons pick it up automatically.

Or simply open an account → **Edit → Upload logo** and choose the image there (it is resized and stored with the account).
Until a logo exists the app shows a clean icon for the account type.
